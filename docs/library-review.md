# 场景模板发布审核

创作者在“详细创建”页导出场景 JSON，可将文件交给项目维护者。投稿文件本身不进入公共模板库。维护者审核后，将模板加入场景数据，并把对应 ID 加入 `lib/reviewed-library.ts`；应用只展示该名单中的模板。

审核时检查：

1. 场景符合 `scenarioSchema`，背景清楚，角色立场具体，开场白可供用户修改。
2. 不包含真实姓名、联系方式、住址、账号密钥等私人资料，也不要求模拟精确复刻现实中的某个人。
3. 不鼓励伤害、骚扰、报复或操纵；强度高时仍保留退出权。
4. 运行九场景回归与新场景的多轮对话测试，确认人物身份和说话视角稳定。
5. 维护者检查导出文件中的背景、角色立场和目标；导出时自动清空的私密笔记不应重新出现在发布版本里。

当前发布库由仓库代码控制。应用内尚无公开投稿或审核后台；任何用户导入的 JSON 只会进入自己的场景编辑表单，不会自动发布。
