# ERIS 已实现功能清单

> 更新日期：2026-11-18。依据当前本地代码整理；“已实现”表示仓库中已有相应界面或逻辑，不等于每个功能都已在生产环境验收。项目面向个人用户。

## 1. 账号与模型接入

| 功能 | 当前实现 |
| --- | --- |
| 手机号形式的账号 | 使用手机号和密码注册、登录；手机号仅作为账号标识，不发送短信验证码。首次登录失败会保留号码并引导到注册表单。密码由 Supabase Auth 管理。 |
| 固定测试账号 | 使用预设账号和暗号登录；账号需预先由脚本建立并在 Auth 的 `app_metadata` 中标记。登录后默认调用服务端配置的项目方 DeepSeek API，不要求再次填写 Key。 |
| 创作者账号 | 从独立的 `/creator` 页面注册、登录，使用与手机号、测试账号不同的内部账号命名空间。账号的模板、对话记录和个人 API Key 按同一用户 ID 关联。 |
| 个人 DeepSeek API | 普通账号和创作者账号可首次保存自己的 Key，以后登录继续使用；支持更换、移除和选择 `deepseek-flash` 或 `deepseek-v4-pro`。Key 在服务端加密保存，不放入聊天记录。 |
| 测试额度 | 开发环境可使用进程内每日计数；生产环境使用 Supabase 数据库额度函数。测试账号的项目方 Key 留在服务端。 |

账号界面见 [交互入口](../app/eris-entry.tsx)、[创作者路由](../app/creator/page.tsx)；注册与密钥处理见 [注册接口](../app/api/auth/register/route.ts)、[个人 Key 存储](../lib/saved-api-key.ts) 和 [测试账号建号脚本](../scripts/provision-test-account.mjs)。

## 2. 场景建立与模板

- **九个项目场景**：发布名单中的固定场景会先进入编辑表单，用户可调整人物、背景、关系、目标、风格和强度，然后再进入对话；开场白也是可编辑草稿。
- **快捷宣泄**：填写事件、对方和想说清楚的事，即可建立场景；可选择关系类型、冲突强度和“用完即删”。没有自动结束的倒计时。
- **详细创建**：支持友情、恋爱关系、人情边界、职场沟通四类提示，填写双方身份、立场、目标、担忧、未说出口的话及不希望涉及的内容；切换类型时保留各自草稿。
- **多人场景**：可设置两到三位虚构角色，并分别填写姓名和立场；回复按姓名显示。当前多人场景不提供换位体验。
- **头像与记忆**：创建时可上传自己与对方的头像；可填写“角色已经知道的背景”，并自行决定是否让模拟角色读取；对话中可修改并保存这一设置。
- **场景文件**：支持导入、导出 ERIS JSON。导出时清空担忧、未说出口的话、记忆和头像；背景及其他字段仍需导出者自行检查。

相关代码：[场景结构与校验](../lib/scenario.ts)、[固定场景数据](../tests/fixtures/qa-scenarios.json)、[发布名单](../lib/reviewed-library.ts)、[场景文件交换](../lib/scene-exchange.ts)。

## 3. 对话体验

- **DeepSeek 对话**：通过服务端接口发起请求；提供宣泄、对峙、冲突续写和换位模式。单段对话最多 15 轮用户表达，角色可依据场景立场及上下文回应。
- **自然对话提示模块**：按关系类型调整口吻，要求回应上一句具体内容、保持角色立场、减少客服式套话；角色理由以场景资料为依据，避免把“忙、有事、难处”当作通用借口。连续重复笼统理由时会尝试重写，且不能补造未给出的事件。在符合情绪的语境中允许感叹号及偶尔连用。它是提示词规则，不是模型微调。
- **结构化回复与校验**：校验台词、情绪、冲突动作、状态变化及转折点候选；限制单轮状态变化，检查多人说话标注与换位视角。模型复述或输出异常时尝试修复或重写，仍失败则提示重试并保留用户输入。
- **聊天控制**：可降低或调整强度、逐渐收尾、暂停、跳出角色、结束、删除，以及从场景设置中修改场景。暂停、跳出角色、结束和继续会先切换页面再保存状态；保存失败会明确提示。角色已知背景收在折叠区。
- **语音与表情**：支持浏览器提供的中文语音识别，转写先进入可编辑输入框；可上传、收藏和发送自定义图片表情；上传时会把压缩图片发给 DeepSeek Flash 识别可能的语气，用户可修改识别结果。对话模型只收到语气文字，不接收图片编码。测试账号的识别调用也会占用项目方测试额度。
- **风险提示**：检测明显激烈表达或高紧张状态并提示先暂停、降低强度；遇到明确自伤或现实暴力表达时停止普通模拟并显示安全提示。规则仅用于界面保护，不是心理诊断。

相关代码：[对话接口](../app/api/chat/route.ts)、[模型回复处理](../lib/deepseek.ts)、[自然对话提示](../lib/voice-skill.ts)、[表情处理](../lib/chat-media.ts)、[情绪升高提示](../lib/escalation-cue.ts)。

## 4. 历史、分支与回看

- **按账号保存**：场景、会话、消息、场景状态、转折点、结局和反馈保存在 Supabase；刷新后先读取最近未完成的会话，再完整显示首页的“继续上一段对话”入口；进行中或已暂停的对话均可从首页或历史记录继续。
- **历史查询**：可查看最近 50 段会话，按场景标题或消息文字搜索，继续未结束的对话，或永久删除场景及关联记录。
- **平行尝试**：从候选转折点重试，生成平行分支；符合条件时可交换角色体验另一种立场。同一场景的尝试按时间线展示，可并列比较已记录的结局。
- **情绪落地与反馈**：暂停或结束前可退出角色；回看由用户主动打开。用户自行选择结局、当下感受，并可提交体验反馈。
- **表达观察**：显示表达轮数、整句重复、犹豫词、感受或请求等字面线索，以及当前页面的键盘停顿；支持用户临时填写自己的练习标准。多次练习展示轮数和模拟状态中的表达覆盖度趋势，不自动评分。
- **文本导出**：历史记录和落地页可导出对话文本，导出前提醒检查私人信息。

相关代码：[持久化](../lib/persistence.ts)、[回看](../lib/reflection.ts)、[表达观察](../lib/expression-analysis.ts)、[练习趋势](../lib/practice-trend.ts)、[文本导出](../lib/conversation-export.ts)。

## 5. 创作者空间与公共场景

- 已建立独立的创作者入口和个人模板库界面，支持创建、编辑、删除、导入个人模板；选择个人模板后可再次微调再使用。
- 模板保存时会清除私人担忧、未说出口的话、可控记忆和头像；个人模板不会自动进入公共场景列表。
- 公共场景当前由仓库内的发布名单控制；审核规则写在[场景发布审核说明](library-review.md)。应用内**没有**公开投稿或审核后台。
- **部署验证**：[数据库迁移](../supabase/migrations/20261117151646_creator_templates.sql)对应的 `creator_templates` 表已可由已登录账号经 Data API 查询；个人模板的创建、编辑和跨账号隔离仍需用真实创作者账号完成端到端验收。

## 6. 数据位置与隐私边界

| 数据 | 保存位置与行为 |
| --- | --- |
| 账号密码 | Supabase Auth；应用数据库不保存明文密码。手机号账号没有短信验证。 |
| 普通场景、对话、状态、反馈 | Supabase PostgreSQL；现有表通过行级权限按用户 ID 隔离。 |
| 个人 DeepSeek Key | 服务端加密后存入当前账号的私有凭据表；需配置加密密钥和 Supabase 服务端密钥。 |
| 创作者个人模板 | 存入 `creator_templates` 私有表；当前连接的远端库已可查询该表，写入和跨账号权限仍待浏览器验收。 |
| “用完即删”对话 | 只在当前页面内存中保留，刷新或离开后无法恢复；模型请求仍会发给 DeepSeek。 |
| 表情包 | 收藏清单及语气标签保存在当前设备的浏览器存储中；已发送的表情和标签随对话消息保存。上传时压缩图会经服务端发送到 DeepSeek Flash 做一次语气识别。 |
| 用户自定练习标准 | 仅当前页面内存，不上传。 |

ERIS 生成的是虚构对话的可能情境，不预测现实人物的想法，也不提供心理诊断或治疗。

## 7. 界面、移动端与验证状态

- 首页、简介页、登录页和聊天页采用响应式布局；创作者有独立页面。首次打开或刷新时先等待最近会话恢复，再一次性显示首页和继续入口；浏览器内复用 Supabase Auth 客户端以减少开发热更新时的会话冲突。
- 提供 Web App Manifest 和图标，可在支持的移动浏览器中添加到主屏幕；聊天与模型调用仍需联网，没有离线模型。
- 本地有 Vitest 单元测试、九个固定场景数据检查，以及调用真实 DeepSeek 的对话验收脚本。本轮验证为 TypeScript 检查、生产构建、**82 项 Vitest 测试通过**；九个固定场景经真实 DeepSeek 接口验收，9/9 成功，另用连续两轮的“忙”借口进行了针对性回测。测试账号登录后可读取最近未完成会话及其场景、消息和状态；创作者模板表可查询。表情图片识别、界面点击和真实创作者模板写入仍需在浏览器端验收。
- 本清单随本轮代码提交；运行与环境变量说明见根目录 [README](../README.md)。
