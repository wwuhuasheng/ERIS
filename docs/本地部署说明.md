# ERIS 本地部署说明

本文说明如何在自己的电脑上运行 ERIS 网页应用。需要 Node.js 20.9 或更新版本、一个 Supabase 项目，以及使用个人模型时的 DeepSeek API Key。

## 1. 安装依赖

首次获取项目时，在终端执行：

```bash
git clone https://github.com/wwuhuasheng/ERIS.git
cd ERIS
npm ci
cp .env.example .env.local
```

如果项目已经在本机，从项目根目录运行 `npm ci` 即可。如果 `.env.local` 已存在，请保留原文件并直接检查其中的配置，不要用示例文件覆盖。

## 2. 准备 Supabase

沿用已经配置过的 ERIS Supabase 项目时，直接进入下一步，不要重复执行初始迁移。使用全新项目时，保持 Email/Password Auth 可用，并按以下顺序应用数据库迁移：

1. [`202611050001_initial.sql`](../supabase/migrations/202611050001_initial.sql)
2. [`202611050002_quota.sql`](../supabase/migrations/202611050002_quota.sql)
3. [`20261115040005_add_private_credentials_and_grants.sql`](../supabase/migrations/20261115040005_add_private_credentials_and_grants.sql)
4. [`20261117151646_creator_templates.sql`](../supabase/migrations/20261117151646_creator_templates.sql)

Supabase 控制台的 SQL Editor 可以执行这些 SQL。手机号在 ERIS 中只是账号名称，内部通过邮箱别名使用 Supabase Auth；无需开启 Phone/SMS，也不会发送短信验证码。

## 3. 填写环境变量

打开项目根目录的 `.env.local`，参考 [`.env.example`](../.env.example) 填写：

```dotenv
NEXT_PUBLIC_SUPABASE_URL=你的Supabase项目URL
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=你的publishable key
SUPABASE_URL=同一个Supabase项目URL
SUPABASE_SECRET_KEY=你的服务端secret key
ERIS_API_KEY_ENCRYPTION_KEY=32字节随机密钥的Base64值
```

可以在终端生成加密密钥：

```bash
node -e 'console.log(require("node:crypto").randomBytes(32).toString("base64"))'
```

请备份这个密钥并保持不变；更换或丢失后，之前保存的个人 DeepSeek Key 将无法解密。`SUPABASE_SECRET_KEY` 和加密密钥只能放在服务端，不能加 `NEXT_PUBLIC_` 前缀，也不要提交到 GitHub。

普通账号登录后，可在页面中首次保存自己的 DeepSeek API Key，以后不必重复填写。启用项目方固定测试账号时，还需填写：

```dotenv
ERIS_TEST_USERNAME=你的测试账号
ERIS_TEST_PASSPHRASE=你的测试暗号
DEEPSEEK_API_KEY=项目方的DeepSeek API Key
```

仅在首次创建测试账号时执行：

```bash
node --env-file=.env.local scripts/provision-test-account.mjs
```

该脚本不会修改已存在账号的暗号。已有测试账号时，保留原账号并跳过此命令。

## 4. 启动项目

```bash
npm run dev
```

浏览器打开 <http://localhost:3000>，注册或登录后进入场景。停止开发服务器时，在终端按 `Ctrl+C`。

需要在本机以生产模式运行时，先构建，再启动：

```bash
npm run build
npm run start
```

## 5. 检查

```bash
npm run typecheck
npm test
npm run build
```

首次部署建议实际完成一次注册、保存个人 API Key、创建对话、刷新后继续对话及查询历史记录，确认当前 Supabase 项目和 DeepSeek Key 都已接通。更详细的功能范围见[已实现功能清单](已实现功能清单.md)。
